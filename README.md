# PFR-TCN-AE

> **Repository status: PLACEHOLDER ONLY - source code is not yet available.**

This repository is reserved for reproducibility materials accompanying the PFR-TCN-AE wind-turbine early-fault-detection manuscript.

## Availability statement

No implementation code, trained model weights, or research data are included in the current repository. The complete online monitoring implementation, configuration files, and reproducibility documentation are being organized and checked for consistency.

The reproducible implementation will be released in this repository after completion of the manuscript review process.

## Planned contents

- Training and inference scripts for PFR-TCN-AE
- Student-t SVGP feasible-region construction
- Causal KDE thresholding and two-stage persistence monitoring
- Configuration files and pseudocode
- Instructions for reproducing the reported evaluation
